## Progetti
 
**[Indrik](https://github.com/xilioscient/-Indrik)** — linguaggio di programmazione di sistema in cui l'assembly è un costrutto di prima classe, non una scocciatura da evitare. Compilatore bootstrap in Rust (`indrikc`), lexer/parser/type checker/borrow checker custom, codegen diretto verso ELF64 e PE32+, nessuna libc, nessun runtime.
 
**[Labyrinth-Mesh](https://github.com/xilioscient/Labyrinth-Mesh)** — tunnel multi-path resistente al post-quantum: KEM ibrido X25519+Kyber-1024, Shamir Secret Sharing 3-su-5 su GF(2⁸), autenticazione BLAKE3, firme Dilithium3, scheduler adattivo multi-path. Modalità HTTP con fingerprint TLS 1.3 identico a Chrome 124 (JA3/JA4) e cover traffic via XDP/eBPF.
 
**[Yurei](https://github.com/xilioscient/yurei)** — pipeline AI on-premise per l'estrazione strutturata da testo aziendale non ordinato. Rust + Python, LLM locale (llama.cpp), classificazione XGBoost/spaCy, storage DuckDB, esposizione REST/OData.
